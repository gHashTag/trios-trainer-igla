A KNOWN HOLE IN THIS EVIDENCE, found while assembling it
  The sidecars in sidecars/ CANNOT distinguish a det-math run from a default
  run. `platform.features` reads
      ci-strict=0,gf16=0,gpu=0,race=0,smoke=0,trios-integration=0
  on BOTH, and `source_sha256` is fda0dd21... on both, while the weight
  digests differ (efef1cba... vs 7459c716...). Two artifacts with different
  bytes carry identical provenance. The cause is that
  `declared_feature_states()` in src/checkpoint.rs is a hand-maintained list
  and `det-math` is not in it. That file is NOT owned by this work item and
  was deliberately not touched. Until it is fixed, the ONLY thing that ties
  7459c716... to a det-math build is this directory.
