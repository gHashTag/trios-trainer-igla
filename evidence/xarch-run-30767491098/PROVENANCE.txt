Evidence package: cross-architecture checkpoint from GitHub Actions run 30767491098
==================================================================================

What this directory is
----------------------

Two files downloaded verbatim from a GitHub Actions artifact and copied here
byte-for-byte. They were NOT produced on this machine and are NOT reproducible
from this repository by running anything locally: they are the x86_64 Linux
half of the one cross-architecture comparison this project has ever made. The
artifact retention window on GitHub is finite; the copy exists so that the
measurement in docs/CROSS-ARCH-DIVERGENCE.md keeps its primary source after
the artifact expires.

Nothing in this directory is regenerated by any script. If a byte changes, the
evidence is gone, not updated.

What this evidence is compared against
--------------------------------------

  checkpoints/r5-adv-recheck/12000.bin
  sha256 8a86fe691aef64fcb637b90d4cf62650c217c3b000b6252846a8ab70c186012c

produced on macos/aarch64 from the same commit. `checkpoints/r4-docs-repro/
12000.bin` in this repository is the same bytes as `r5-adv-recheck/12000.bin`
(both hash to 8a86fe69...), so the canon-name difference between the two
sidecars is a directory name and nothing else.

Comparing the two sidecars field by field, exactly these fields differ:

  sha256, path, canon_name, platform, trainer, ts, git_dirty,
  final_val_bpb, best_val_bpb, ema_bpb

Everything else - seed, step, steps_total, hidden, d_model, num_attn_layers,
vocab, optimizer, fake_quant_format, lr, attn_scale, attn_seq,
gf16_floor_every, eval_every, data_synthetic, format_version, git_sha,
source_sha256 and all three corpus hashes - is identical. In particular
`source_sha256` is identical, which is the check that matters: the aarch64
sidecar records `git_dirty: true` at the same `git_sha`, and the matching
`source_sha256` is what shows the dirt did not reach the trainer source.

That is what makes the comparison in docs/CROSS-ARCH-DIVERGENCE.md a paired
one: one variable, the platform, is different, and every recorded ingredient of
the recipe is the same.

Reproducing the analysis
------------------------

  python3 scripts/compare_checkpoints.py \
      evidence/xarch-run-30767491098/12000.bin \
      checkpoints/r5-adv-recheck/12000.bin

writes docs/cross-arch-divergence.json, from which every number in
docs/CROSS-ARCH-DIVERGENCE.md is taken.
