RETRACTED EVIDENCE - DO NOT CITE, DO NOT PARSE AS A LEDGER
==========================================================

This file was `assertions/seed_results.jsonl`, declared the source of truth for
IGLA RACE BPB evidence by SOURCE_OF_TRUTH.md, MIGRATION.md,
docs/TRAINING_FLOW_V2.md, docs/preregistration/asymlogit_ngram_v1.md and
igla-dash/README.md. It is renamed and retracted. See RETRACTION.md at the repo
root for the full accounting, including the three other BPB numbers that
coexisted with these rows.

Nothing below has been altered. The rows are preserved verbatim so the retraction
can be checked against what was actually published.

WHY EVERY ROW IS UNCITABLE (applies to all 11 rows)
---------------------------------------------------
- No artifact. Both referenced commits carry `checkpoint::save` as a stub:
  `pub fn save(_run, _step, _bytes) -> anyhow::Result<()> { Ok(()) }`
  (checkpoint.rs:116-119 at 4c0b04c and at cd91c45). No weights were written by
  any run that produced these numbers, so no row can be re-measured.
- No corpus hash. No row names a corpus file, a byte count or a digest. At both
  commits `load_data` silently substituted a synthetic corpus when the path was
  missing - `b"The quick brown fox jumps over the lazy dog. ".repeat(2500)`,
  train_loop.rs:39-51 - printing only `Data file '...' not found, using
  synthetic fallback` to stderr. Nothing in a row distinguishes a real corpus
  from that 112 500-byte pangram, and in the fallback case train and val are the
  same bytes.
- No trainer hash. `sha` is a 7-character abbreviation of the repository HEAD.
  It pins no binary, no toolchain, no config and no data. The row carries no
  config digest, so which of the several TOMLs in `configs/` produced it is not
  recorded.
- No eval coverage. No row records how much of the validation set was scored:
  no val token count, no eval window count, no eval cadence. At these commits
  `--eval-every` was not an observation-only parameter (it gates an in-place
  weight transform late in training), so two rows with different cadence are not
  comparable - and the cadence is not in the rows.
- Forbidden seeds. Every seed here is 42, 43 or 44. `src/seed_canon.rs` declares
  {42, 43, 44, 45} FORBIDDEN under Canon #93 and the allowed canon set to be
  {47, 89, 123, 144}. No row in this file uses a canon-allowed seed.
