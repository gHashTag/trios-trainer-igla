# `data/loop49/` — empirical anchor for the Loop 49 sign-flip finding

This directory contains the canonical empirical CSVs that
`papers/f2_methodology.md` and `docs/F2_RMS_CDE.md` cite as the source
of the headline finding (RmsNorm NDE flips sign across strata).

Anchoring the data in the repo (rather than relying on `/tmp/`) closes
the reviewer reproducibility checklist in `papers/f2_methodology.md`
§3.5.4: every figure and every numerical claim in §5 should regenerate
from these six files plus a `git checkout` of this branch.

## Reproducing each file from scratch

Each CSV can be regenerated by running the appropriate F2 binary at the
anchor commit (`5367bde` or any descendant).

```bash
# Anchor commit
git checkout 5367bde

# loop47_warmup_stratified.csv
cargo run --release --bin f2_ablation_sweep -- \
  --mode warmup_stratified --steps 200 \
  --csv data/loop49/loop47_warmup_stratified.csv

# loop49_wd_stratified.csv
cargo run --release --bin f2_ablation_sweep -- \
  --mode wd_stratified --steps 200 \
  --csv data/loop49/loop49_wd_stratified.csv

# loop49_warmup0_dual.csv (Pearl CDE at warmup=0)
cargo run --release --bin f2_dual_mediation -- \
  --m1 wd --m2 warmup data/loop49/loop47_warmup_stratified.csv \
  --out data/loop49/loop49_warmup0_dual.csv

# loop49_wd0_dual.csv (Pearl CDE at WD=0)
cargo run --release --bin f2_dual_mediation -- \
  --m1 wd --m2 warmup data/loop49/loop49_wd_stratified.csv \
  --out data/loop49/loop49_wd0_dual.csv

# loop36_dual.csv (canonical mediation, M1=wd, M2=warmup)
# Requires the canonical loco/pairwise/triplet CSVs from Loop 28/29:
# (see git history at commit 6ac812d for the original sweep commands)

# loop49_3stratum.csv (Figure 1 source)
cargo run --release --bin f2_stratum_compare -- \
  --canonical data/loop49/loop36_dual.csv \
  --wd0       data/loop49/loop49_wd0_dual.csv \
  --warmup0   data/loop49/loop49_warmup0_dual.csv \
  --out       data/loop49/loop49_3stratum.csv
```

## Schema reminders

- Every CSV starts with a `# prov:*` W3C-PROV preamble per
  `papers/f2_methodology.md` §3.5.1 (modulo legacy stripping).
- `f2_dual_mediation` outputs include the `# INPUT STRATUM = ...`
  banner per §3.5.3.
- Run `cargo run --release --bin f2_provenance_check -- <file>` to
  validate before consuming downstream.

## Determinism caveat

These CSVs are produced by a deterministic Rust trainer using fixed
seeds `[42, 43, 44, 45, 46]`. Reproducing them byte-for-byte requires
the same `TRAINER_INTERNALS_SCHEMA` version (currently
`trainer_internals_v1_2026_06_01` — see `src/race/multi_seed.rs`). If
that constant is bumped, the BPB numbers will differ even at identical
config hashes; the schema-version mismatch will surface as a `FAIL`
from `f2_provenance_check`.

For the present commit (`5367bde` and ancestors back to `6ac812d`), the
schema is unchanged, so checksums above are stable across the F2
methodology branch.
